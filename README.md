# Google-GenAI-Python-Mini-Bot

A simple, interactive terminal-based conversational agent built in Python using Google's modern google-genai SDK. This project was built as part of a learning course to explore multi-turn conversational AI sessions.

Features
Continuous Multi-Turn Chat: Retains conversational history across messages during the session.

Minimal Implementation: Built with under 20 lines of clean, readable Python code.

Graceful Exit: Type exit to close the conversation loop at any time.
